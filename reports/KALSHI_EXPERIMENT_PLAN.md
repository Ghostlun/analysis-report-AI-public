# Kalshi 페이퍼 Experiment 계획: 확률 우위 진입 검증

목적: CSV로 확인할 수 없는 항목(지연, 호가 깊이, 호가 신선도)을 실측해 "확률 우위 진입"이 실제로 체결·수익이 되는지 확인한다.
이 문서는 계획일 뿐이다. 앱 코드와 설정은 변경하지 않았고 주문도 넣지 않았다. 앱의 Experiment 기능(`backend\app\services\paper_experiments.py`)에서 실험을 만들 때 참고한다.

## 1. 가설
- H1: BTC 우세 쪽을 `Φ(거리/(σ·√남은초)) − (ask + 슬리피지 + 수수료) ≥ 0.04`일 때 사면 정산 보유 기준 수수료 후 ROI가 양수다.
- H2: 평가 주기가 1~5초이므로 지연은 15초 가정보다 훨씬 작고, 우위가 남는다.
- H3: 호가 깊이가 충분해 $5 예산이 대부분 체결된다.
- 기각 조건: 아래 판정 기준을 만족하지 못하면 우위가 없는 것으로 본다.

## 2. 실험 구성

| 실험 | 규칙 | 용도 |
|---|---|---|
| E0 기준선 | 현재 `five_minute_95cent_force_v1` | 비교 기준 |
| E1 확률 우위 | 마감 30~300초 전, BTC 우세 쪽, `P − cost ≥ 0.04`, 정산까지 보유, 시장당 1회 | 주 후보 |
| E2 z 규칙 | ask ≤ 0.99, z ≥ 1.5, 30~240초 전 | 보조 후보 |
| E3 마진 변형 | E1에서 마진 0.00 / 0.08 | 인접 설정 점검 |

- 모든 실험은 같은 시장, 같은 시각의 호가를 사용한다(같은 신호 입력을 비교하기 위해).
- 최대 지출은 거래당 $5(수수료 포함), 정수 계약, 시장당 진입 1회.
- σ(현재 4.275 $/√s)는 개발 데이터 추정치다. 실험에서는 두 가지를 병행 기록한다: 고정 4.275와 직전 N시간 실현 변동성(N은 사전에 정해 실험 중 바꾸지 않는다).

## 3. 매 신호마다 기록할 항목 (최소)

| 구분 | 필드 |
|---|---|
| 신호 | experiment_id, market_ticker, signal_ts, 남은초, BTC, target, 거리, z, σ, 모델 P, 마진 |
| 호가 | 신호 시점 YES/NO ask·bid, 호가 수량(top-of-book size), 호가 깊이(가능하면 3단계), 호가 시각 |
| 주문 | order_ts, 신호→주문 지연(ms), 주문 수량, 지정가 |
| 체결 | fill_ts, 체결가, 체결 수량, 미체결 수량, 수수료, 신호 시점 ask 대비 슬리피지 |
| 정산 | 공식 정산 결과(YES/NO), 정산가, 실현 손익, 예측 손익 |
| 스킵 | 스킵 사유(깊이 부족, 지연으로 호가 이동, 예산 초과, 마진 미달, 시간 초과) |

미체결과 스킵도 반드시 기록한다. 체결된 거래만 보면 선택 편향이 생긴다.

## 4. 분석 지표

- 예측 vs 실제: 모델 P와 실제 승률(보정 곡선), 예측 ROI와 실제 ROI.
- 지연: 신호→주문 지연별 슬리피지와 미체결률.
- 깊이: 요청 수량 대비 체결 수량 비율, 상위 호가 수량 분포.
- 기존 보고서와 같은 지표: 거래 수, 승률, 손익분기 승률, 순손익, 지출, ROI, 최대 낙폭, 최장 연패, 일별 결과, 부트스트랩 신뢰구간.

## 5. 판정 기준 (사전에 고정)

- 최소 표본: 서로 다른 날짜 10일 이상, E1 체결 거래 150건 이상.
- 채택 조건(모두 충족):
  1. 실제 체결 기준 수수료 후 ROI가 양수이고 신뢰구간 하한이 0 근처 이상이다.
  2. 예측 ROI 대비 실제 ROI가 절반 이상이다.
  3. 체결 수량 비율이 평균 70% 이상이다.
  4. 일별 결과가 한 날에 몰려 있지 않다(최고 하루를 빼도 양수).
  5. E0보다 낫다.
- 결과가 기준에 못 미치면 "우위 없음"으로 기록한다. 중간에 규칙이나 파라미터를 바꾸면 표본을 새로 시작한다.

## 6. 주의
- 현재 결과(개발 +43%, 검증 +45%)는 호가가 낡은 값이 아니고 top-of-book에서 체결된다는 가정에 의존한다. 이 실험이 바로 그 가정을 확인한다.
- 시장 구간은 약 9일, 한 가지 장세다. 변동성이 다른 장세가 포함될 때까지 결론을 일반화하지 않는다.
